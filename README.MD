# Projeto Tuberculose

## Backend API

This repository contains a Flask-based backend for recording and retrieving patient exam data related to tuberculosis.

### Run the backend server

1. Open a terminal in the project root:
   ```powershell
   cd c:\Users\Pedro Augusto\Documents\Atitus\projetos\5o_semestre\projeto_tuberculose\backend
   ```
2. Start the server using Python:
   ```powershell
   python run.py
   ```
3. The backend runs on:
   ```text
   http://127.0.0.1:7000
   ```
